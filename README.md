## Research and developer tooling

- [LAIcode](https://github.com/ShubhendraGautam/laicode) studies whether
  discovered program abstractions reduce synthesis cost on unseen tasks, with
  preregistered falsifiers and reproducible experiment records.
- [gator-tools](https://github.com/ShubhendraGautam/gator-tools) provides
  multi-agent repository coordination and a cross-language canonical JSON
  contract with frozen vectors and differential testing.
- [Xplanyexez](https://github.com/ShubhendraGautam/xplanyexez) builds
  evidence-backed hardware inventories with provenance, privacy-preserving
  defaults, and isolated probes.

## Engineering principles

- Verify low-level behavior instead of treating it as a black box.
- Separate demonstrated results from hypotheses and future work.
- Make experiments deterministic, replayable, and explicit about limitations.
- Keep architecture boundaries small enough to replace and test.
